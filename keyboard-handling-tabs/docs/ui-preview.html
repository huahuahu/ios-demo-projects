Keyboard Handling Tabs UI Preview

这个页面用网页 mock 展示 demo 的大概 UI：每个 tab 都是滚动内容区，底部 composer 包含 action buttons、输入框和 Send。SwiftUI 用 sheet 承载来源选择；UIKit 用普通底部 attachmentPanel 配合约束动画替代 inputView 切换。

SwiftUI sheet presentation

SwiftUI tab 保留 ScrollView 和 safeAreaInset(edge: .bottom) 的输入栏。点击 Attach 后不模拟替换键盘，而是打开 .sheet 选择来源。
